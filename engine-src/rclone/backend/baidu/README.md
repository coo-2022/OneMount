# 百度网盘后端

百度个人网盘开放平台后端，协议逻辑移植自本地 OpenEarth-Data 的 Rust 百度适配器。沿用 rclone 的 VFS、缓存、配置加密和 WinFsp 挂载；没有为百度修改 VFS 核心。

支持分页列目录、中文路径、容量、目录创建、范围下载、4 MiB 分片上传与覆盖、文件及目录移动/改名、文件删除和空目录删除。下载校验 Range、长度和前后版本；上传检查分片 MD5、最终提交结果和文件大小。下载链接每次重新获取，逐次验证跳转主机。

## 授权

在被 Git 忽略的 `oauth-clients.local.json` 中配置 `baidu.clientId`（AppKey）及 `baidu.clientSecret`（SecretKey）。应用通过 `src/baidu-auth.cjs` 获取设备码，在官方浏览器页面输入界面显示的短码后授权。取消会终止轮询。令牌通过 RC 写入加密的 rclone 配置；刷新使用标准 OAuth token source 并持久保存新令牌。

应用密钥不能提交到仓库；包含私有配置的本地软件包也不应上传到公开发行页。设备码、令牌、完整响应和下载地址不写入应用诊断日志。

## 边界

- 支持网盘直连和 JuiceFS 文件系统卷。后者通过本机认证 S3 网关保存数据块；应用先在连接的根目录下创建独立卷目录，再以该目录启动网关，不改变本后端的目录边界校验。
- 实际账号验证发现开放平台拒绝零字节文件（errno 10）。后端仍返回标准 `ErrorCantUploadEmptyFiles`，不宣称上传成功。直连 VFS 中的新建空文件会保留待上传状态，需要写入内容或由用户删除后才可安全卸载；非空文件截断为零也不能直接同步。JuiceFS 卷中的空文件及截断由元数据表达，不需要上传零字节对象。
- 上传 API 要求预先提供所有分片摘要。因此上传前会在系统临时目录生成一份完整快照，正常结束或报错时删除。这部分额外磁盘空间不包含在 VFS 的缓存目标中；进程异常终止可能留下 `cloud-island-baidu-upload-*` 临时文件。
- 只接受已知大小的上传；单次上传内存按分片分配，不缓存整个文件到内存。当前逐片上传。
- 不声明全文件 MD5 能力；百度返回的 MD5 不保证等于原始内容摘要。不支持单独修改远端文件时间，也不提供跨设备写入协调。
- 兼容同一目录响应中父路径大小写不一致（如 `Camera` / `camera`）：保留服务端路径和文件名，查找优先精确匹配，大小写兼容匹配存在歧义时拒绝操作。不声明整个文件系统大小写不敏感。仍检查目录归属、重复 ID、重复显示名称及下载前后文件身份和版本。
- 下载速度、文件大小和目录写权限受账号及应用授权限制。限流、空间不足和授权失效会返回失败并保留 VFS 待上传文件。
- HTTP 模拟测试不能代替真实百度账号验收；真实限流、断网恢复、授权刷新和配额耗尽仍需单独验证。

## 测试

在 `engine-src/rclone` 执行 `go test ./backend/baidu/...`。覆盖分页、中文名、范围与短读校验、临时链接跳转、上传分片和提交失败、过期令牌重试、429/5xx、取消及逐文件错误。

真实挂载测试必须使用专门新建的随机目录，校验上传后卸载及冷缓存回读，并且只删除该测试创建的文件。不得对已有用户文件执行通用后端破坏性测试。
