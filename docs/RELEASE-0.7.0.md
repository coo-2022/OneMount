# 云屿 0.7.0 · Windows x64 预览版

## 本版更新

- 打通 JuiceFS 文件系统卷使用百度网盘、Google Drive、OneDrive 等连接作为后端存储的链路；文件分块保存在独立目录，元数据保存在本机。
- 新建文件系统卷默认开启本地持久暂存与后台上传；磁盘的缓存页支持开关后台上传、配置缓存目标。已存在的卷保留原配置。
- 有待上传数据时阻止关闭后台上传；初始化失败允许安全重试，保留 SQLite 元数据及 WAL；卸载失败保留后台会话和缓存。
- JuiceFS 卷在 Windows 中注册为本地固定磁盘，沿用当前用户访问权限。
- 修复本机 S3 网关并发创建目录和对象重试竞争；调整云端慢速读取超时及 OneDrive 上传并发。
- 保存按重要程度、功能及来源划分的 364 项测试清单、1149 条执行记录、补充测试运行器和失败证据；CI 加入本地磁盘及缓存切换回归。

## 下载与升级

完整解压 `OneMount-0.7.0-windows-x64-public.zip`，运行 `CloudIsland/CloudIsland.exe`。
附带 SHA-256 校验文件；首次挂载需要安装 WinFsp。升级前在旧版中执行“安全退出”，
保留 `%APPDATA%/CloudIsland` 中的账号、元数据和缓存。已有卷重新挂载后应用本地磁盘类型。

公开包沿用仓库中的 OAuth 应用配置，不包含开发者本机应用密钥、账号令牌或个人数据。
目前包含 OneDrive 应用 ID；Google Drive、百度网盘、Dropbox 的首次登录需要发布者在构建时配置自己的应用凭据，见 README 中的“自有品牌账号授权”。
本次仅提供 Windows x64 预览包。

## 验证与已知边界

63 项单元测试通过。本地固定磁盘已验证同步／后台上传、当前用户读写、重命名、删除、
上传排空、安全卸载、切换缓存模式及空读缓存重挂后的哈希一致性。实际百度卷已确认注册为本地磁盘。

综合验证复用了历史网盘结果，并新增 145 条执行记录：93 通过、50 失败、2 超时。
这些综合语义结果对应本地磁盘变更前的网络盘基线；不能视为新挂载类型的全量验收。
命名流、扩展属性、部分权限／属性／重解析点等 Windows 语义仍有差异。

**JuiceFS 刷新长超时后截断不一致的问题仍未修复**：截断可能先返回成功，随后旧写入完成又改变文件长度。
本地持久缓存及短时故障恢复通过不代表该问题已解决。写入缓存没有独立硬容量上限；缓存目标不限制全部待上传数据。
文件系统卷当前面向单机使用；本机元数据与未上传缓存需要保留。本版尚未代码签名。

详细结果见[综合验证](FILESYSTEM-VALIDATION-2026-10-16.md)、[本地磁盘回归](JUICEFS-LOCAL-DISK-VALIDATION-2026-10-16.md)及[测试矩阵](FILESYSTEM-TEST-MATRIX.json)。
